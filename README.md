# Sistema de Hospedagem
Aplicativo construído para gerenciamento de um Hotel, realização CRUD de hóspedes, CRUD de quartos e realizar reservas de quartos.

### Tecnologias 

  - [Django](https://www.djangoproject.com/)
  - [React](https://reactjs.org/)
  - [Javascript](https://www.javascript.com/)

### 🚀 Instalação

Clone o projeto

```sh
$ git clone https://github.com/brenolimeira/gerenciar-hotel.git
```

Para Instalar todas as dependências do projeto use:

```sh
$ npm i
```

### Desenvolvimento

Para iniciar e contribuir com o projeto use as seguintes linhas de comando

Para iniciar aplicativo:
```sh
$ npm start
```
